Project: DuckLock — Reels-Lock ka ek screen fix karna hai
Screen ka naam/context: Ye jo screen hai iska naam "ReelCountScheduleScreen" hai — ye us waqt khulti hai jab user Settings mein "Unlock" option (jo teen alag entries mein clone hui hai — "Unlock One" = Instagram, "Unlock Two" = YouTube, "Unlock Three" = Facebook) use karke, aur diye gaye 5 tasks mein se koi ek task poora complete karta hai. Task complete hote hi, ye screen khulti hai jahan user ko decide karna hota hai ki wo kitne reels dekhna chahta hai us waqt ke liye, uske baad wapas lock lag jaata hai.
Screen ka current layout: Top-left mein ek round back-button hai (dark circle, transparent background, andar plain chevron-arrow icon). Uske neeche, center mein ek phone-mockup jaisa illustration/character-image dikh raha hai. Uske neeche heading-text hai — jo abhi galti se Hindi mein likha hua hai: "Kitne Reels dekhne hain?". Uske neeche 6 pill-shaped dark buttons hain — 2 columns x 3 rows mein — values: 5, 10, 20, 30, 40, 50 — user in mein se koi ek number select karta hai (kitne reels dekhne hain). Sabse neeche ek orange/peach-gradient "Confirm" button hai.
Problem 1 — Character-image bahut chhota hai:
Abhi jo character-illustration center mein dikh raha hai, wo bahut chhota render ho raha hai — screen ke total width ka sirf takriban 25-30% jitna hi jagah le raha hai. Ye bahut zyada bada hona chahiye — takriban screen-width ka 65-70% jitna. Image ka resizeMode: "contain" rakhna hai taaki proportion bigड़e nahi, sirf overall size badhana hai. Agar code mein kahin fixed chhoti pixel-value hardcoded hai (jaise width: 120, height: 120 ya kuch is type ka), to use hataake bada dimension ya percentage-based sizing lagani hai. Character horizontally center rahega screen mein, aur uske aas-paas thoda proper gap/margin bhi rahega — na to bahut edge tak jaaye, na bahut chhota reh jaaye.
Problem 2 — Heading text Hindi mein hai, English mein chahiye:
Abhi jo heading "Kitne Reels dekhne hain?" likha hua hai, use badalkar English mein ye likhna hai: "How many reels do you want to watch?"
⚠️ Bahut zaroori warning — reference-image ke baare mein:
Main tumhe ab ek reference-image bhejunga. Is reference-image ka istemal SIRF aur SIRF ye samajhne ke liye karna hai ki character-illustration ka size kitna bada hona chahiye, aur wo screen par kahan (kis position par) hona chahiye — matlab sirf spatial-adjustment/alignment/proportion ki jaankari lena hai us image se.
Us reference-image mein se koi bhi aur cheez copy, reproduce, ya replicate NAHI karni hai — na uska text, na uska specific artwork/design, na uska koi bhi content, na koi aur visual-element. Sirf "kitna bada dikhna chahiye aur kahan position hona chahiye" — bas itni si guidance leni hai us reference se, aur kuch bhi nahi.
Jab tak main specifically na kahoon, us reference-image se koi aur cheez implement mat karna. Sirf upar diye gaye 2 problems (character-size aur heading-text) ko fix karna hai — is se zyada kuch bhi apne se add, change, ya assume mat karna.
